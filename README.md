# Sanyi_The_Assistant

## Description

This script got the idea from a movie and is intended to help the user with every daily or work-related task by providing a basic and faster way to finish the given task.

The main language of the project is Python, with any additional languages being used when necessary.

For now, this project is just an idea and still needs some work to fully realize the concept.

The tasks included with the standard installation are mainly intended for programmers and basic task or idea management.

For example:
- Creating and updating GitHub repositories
- Creating and updating Trello tables
- Managing existing repositories and tables
- Helping with basic programming-related tasks
